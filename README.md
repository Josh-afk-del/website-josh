# Website Josh

Static website and strategy brief for Josh Roche.

## Local Preview

```bash
npm run dev
```

Then open `http://127.0.0.1:3000`.

## Vercel

This project is a static site. Vercel can deploy it from the repository root with no build command and the output directory left blank.

Key routes:

- `/` - Josh Roche website
- `/strategy-brief/` - offer stack and content strategy presentation
